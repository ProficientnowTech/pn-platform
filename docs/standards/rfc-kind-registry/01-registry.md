---

## 1.2 Kind Status Values

| Status | Meaning |
|--------|---------|
| Active | Kind is available for use in new RFCs |
| Deprecated | Kind should not be used for new RFCs; existing RFCs may continue |
| Retired | Kind is no longer valid; existing RFCs should be migrated |

## 1.4 Kind Usage Summary

| Kind | Use When |
|------|----------|
| Standards | Defining how to write RFCs or RFC standards |
| Architecture | Describing system behavior, trust boundaries, invariants |
| Specification | Defining implementation prerequisites, resources, validation |
| BCP | Documenting operational procedures, guidelines, practices |
