## Term Definitions

### Active (Kind Status)

A kind status indicating the kind is available for use in new RFCs. Active kinds are fully supported.

### Deprecated (Kind Status)

A kind status indicating the kind should not be used for new RFCs. Existing RFCs using the kind may continue, but authors should plan migration.

### Governing RFC

The RFC that defines a kind's structure, requirements, and validation criteria. Each kind has exactly one governing RFC.

### Kind

A classification of RFC that determines its structure and purpose. All kinds MUST be registered in this registry.

### Kind ID

A short identifier (usually 4 characters) uniquely identifying a kind. Examples: STND, ARCH, SPEC, BCP.

### Registry

The authoritative list of recognized RFC kinds. Only kinds in this registry may be used in RFC metadata.

### Retired (Kind Status)

A kind status indicating the kind is no longer valid. Existing RFCs using the kind should be migrated to a replacement kind.
