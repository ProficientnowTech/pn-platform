## Abstract

This RFC defines the Standards kind—meta-RFCs that define how to write other RFCs. Standards RFCs establish normative requirements for RFC authorship, structure, formatting, and validation.

This document is self-referential: it defines the structure for Standards RFCs and itself follows that structure.

Standards RFCs are the foundation of the RFC system. They define:

- Required and optional sections for each RFC kind
- Formatting and style requirements
- Validation criteria for compliance
- Examples demonstrating proper usage
